## 📌 Giới thiệu dự án

**20/22 Takeaway** là mô hình kinh doanh đồ uống mang đi tập trung vào ba dòng sản phẩm chủ lực: **Matcha, Coffee và Milktea**, phục vụ trực tiếp tại khu vực Cơ sở 5 LHU và cư dân lân cận. Dự án giải quyết bài toán giúp khách hàng nhận biết món nhanh, nắm rõ mức giá dễ tiếp cận (20k–22k) và dễ dàng tìm thấy điểm bán thông qua hệ thống nhận diện đồng bộ từ không gian số đến điểm bán thực tế.

Toàn bộ đồ án đã được số hóa thành một **Web Portfolio tương tác cao** (sử dụng font chữ Baloo, hiệu ứng Cinematic Smooth Scroll), tích hợp đầy đủ giao diện Landing Page, báo cáo chi tiết và slide trình chiếu trực tiếp trên GitHub Pages.

## 📂 Cấu trúc Thư mục Dự án

```text
20-22-takeaway-v2/
├── index.html              # Trang chủ Landing Page (Cinematic Dark Mode, Font Baloo, Carousel)
├── report.html             # Trang báo cáo chi tiết học thuật (Phân tích dữ liệu TikTok & Phễu nội dung)
├── presentation.html       # Giao diện Slide trình chiếu bảo vệ đồ án (Không cắt xén hình ảnh, đúng tỷ lệ chuẩn)
├── README.md               # Tài liệu mô tả dự án
└── assets/
    └── images/             # Kho hình ảnh quảng cáo, POSM và Mockup thực tế (18 file chuẩn)
```

## ✨ Các tính năng nổi bật trên Web Showcase

1. **Trang chủ (Landing Page - `index.html`):** Giao diện cuộn mượt mà với font chữ Baloo, trưng bày Best Seller Collection và các ấn phẩm thiết kế đúng tỷ lệ chuẩn (Post 4:5, Standee 850mm x 2000mm, Brochure A5).
2. **Báo cáo chi tiết (`report.html`):** Trình bày toàn bộ phân tích chiến dịch nội dung TikTok, bảng Share Rate và ma trận CLO.
3. **Slide trình chiếu (`presentation.html`):** Thiết kế trực quan side-by-side phục vụ thuyết trình bảo vệ trước hội đồng, giữ nguyên vẹn hình ảnh, không cắt xén.

## 🛠️ Hướng dẫn Triển khai trên GitHub Pages

1. Đẩy toàn bộ mã nguồn và thư mục `assets/images/` lên repository trên GitHub của bạn.
2. Vào tab **Settings** của Repository $\rightarrow$ chọn mục **Pages**.
3. Tại phần **Build and deployment**, chọn Branch là `main` và thư mục `/root` $\rightarrow$ Nhấn **Save**.
4. Truy cập đường link GitHub Pages được cung cấp để trình chiếu đồ án.
